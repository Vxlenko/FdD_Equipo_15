## Circuito 1

<img src="/Recursos/Imágenes/Circuito1.jpeg">

**Datos:**

- R1 = 220 Ω
- R2 = 220 Ω
- R3 = 200 Ω
- R4 = 2000 Ω
- R5 = 22 Ω

**NOTA:** R5 no interviene en el cálculo.

### 1. Serie

R12 = R1 + R2

R12 = 220 + 220

R12 = 440 Ω

### 2. Paralelo

1/Req = 1/R12 + 1/R3 + 1/R4

1/Req = 1/440 + 1/200 + 1/2000

1/Req = 0.002273 + 0.005 + 0.0005

1/Req = 0.007773

Req = 1 / 0.007773

Req = 128.65 Ω

## Circuito 2

<img src="/Recursos/Imágenes/Circuito2.jpg">

**Datos:**

- R1 = 220 Ω
- R2 = 220 Ω
- R3 = 200 Ω

### 1. Serie

R12 = R1 + R2

R12 = 220 + 220

R12 = 440 Ω

### 2. Paralelo

Req = (R12 × R3) / (R12 + R3)

Req = (440 × 200) / (440 + 200)

Req = 88000 / 640

Req = 137.5 Ω

## Circuito 3

<img src="/Recursos/Imágenes/Circuito3.jpg">

**Datos:**

- R1 = 220 Ω
- R2 = 2000 Ω
- R3 = 220 Ω
- R4 = 200 Ω
- R5 = 220 Ω
- R6 = 22 Ω

### 1. Resistencias en serie

R13 = R1 + R3

R13 = 220 + 220

R13 = 440 Ω

R24 = R2 + R4

R24 = 2000 + 200

R24 = 2200 Ω

R56 = R5 + R6

R56 = 220 + 22

R56 = 242 Ω

### 2. Paralelo

1/Req = 1/R13 + 1/R24 + 1/R56

1/Req = 1/440 + 1/2200 + 1/242

Req = 1 / (1/440 + 1/2200 + 1/242)

Req = 145.78 Ω
