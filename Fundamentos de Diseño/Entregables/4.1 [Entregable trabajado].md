## Tabla de exigencias

| Fecha (cambios) | Clase | Descripción | Responsable |
|---|:---:|---|---|
| | | **FUNCIÓN PRINCIPAL:** | |
| | E | El sistema debe automatizar el riego de áreas verdes, jardines y parques residenciales o asentamientos humanos, mediante un sensor de humedad de suelo que determine cuándo activar o detener el suministro de agua, sin intervención manual continua del usuario. | Todos |
| | | **GEOMETRÍA:** | |
| | E | El sistema debe tener una estructura compacta y modular, con dimensiones aproximadas de 20 x 15 x 10 cm, que permita integrar el controlador, los sensores y las conexiones eléctricas e hidráulicas en un único módulo. | Leonardo |
| | E | La caja de control debe poder instalarse a una distancia máxima de 1 metro del área de riego, sin interferir con el tránsito de personas ni con el mantenimiento de las áreas verdes. | Leonardo |
| | D | La carcasa debe permitir una reducción adicional de tamaño para facilitar su transporte y almacenamiento entre sesiones de prueba. | Leonardo |
| | | **CINEMÁTICA:** | |
| | E | El sistema debe accionar como mínimo una electroválvula o minibomba mediante una salida eléctrica controlada por relé, sin generar movimientos que representen riesgo para el usuario. El tiempo entre la señal de activación emitida por el controlador y la apertura o cierre efectivo del actuador no debe superar los 5 segundos, de acuerdo con la hoja técnica del componente seleccionado. | Leonardo / Leonel |
| | | **FUERZAS:** | |
| | E | La estructura, los soportes y las conexiones deben soportar el peso de los componentes instalados, vibraciones leves durante el funcionamiento y la presión de trabajo de la red de agua (máximo 40 PSI), sin presentar deformación visible. | Leonardo |
| | E | Las tuberías deben quedar fijadas mediante abrazaderas o soportes, sin transmitir esfuerzo mecánico directo sobre los sensores ni sobre las válvulas conectadas. | Leonardo |
| | | **MATERIA:** | |
| | E | La carcasa del prototipo debe fabricarse con un material aislante eléctrico y resistente a la humedad y a la radiación solar directa (por ejemplo, PVC o ABS), adecuado para instalación en exteriores. Las tuberías, uniones y sellos deben ser compatibles con el paso de agua de riego y con el diámetro nominal definido para el prototipo (mínimo 1/2 pulgada), evitando corrosión o degradación del material. | Leonel (Willians) |
| | | **ENERGÍA:** | |
| | E | El prototipo debe contar con una fuente de alimentación de 5V o 12V DC (según el componente), regulada, capaz de alimentar de forma simultánea al microcontrolador, los sensores y el sistema de accionamiento durante al menos 4 horas de operación continua. La distribución eléctrica hacia el controlador, los sensores y el actuador debe incluir protección contra sobrecorriente (fusible o diodo de protección) para evitar daños a los componentes. | Leonel / Kenneth |
| | | **SEÑALES:** | |
| | E | El sensor de humedad de suelo debe enviar una lectura (digital o analógica) al microcontrolador cada 30 segundos como máximo, con un margen de error no mayor a ±5% respecto al valor real de humedad. El controlador debe recibir y procesar la señal del sensor sin pérdida de datos, generando una salida de control coherente con el valor leído en cada ciclo de muestreo. | Leonel / Giordano |
| | | **CONTROL:** | |
| | E | El sistema debe comparar el valor de humedad medido contra un umbral programado: si la humedad es menor al umbral, debe activar el riego; si es igual o mayor, debe detenerlo, con una histéresis mínima que evite activaciones repetidas en corto tiempo. El riego debe ejecutarse de forma automática durante la operación normal, permitiendo además una anulación manual por parte del usuario en caso de emergencia. | Leonel / Giordano |
| | | **ELECTRÓNICA:** | |
| | E | El prototipo debe integrar un microcontrolador con conectividad WiFi (por ejemplo, ESP32), un sensor de humedad de suelo capacitivo y un módulo relé que accione la electroválvula o bomba. Las conexiones eléctricas deben realizarse siguiendo el diagrama de conexión aprobado por el equipo, con cables etiquetados y terminales protegidos contra falsos contactos. | Leonel / Leonardo / Giordano |
| | | **SOFTWARE:** | |
| | E | El programa debe leer el sensor de humedad en intervalos regulares (máximo cada 30 segundos), ejecutar la lógica de comparación contra el umbral establecido y activar o detener el riego en consecuencia, sin bloqueos ni reinicios inesperados. El software debe permitir modificar el valor del umbral de humedad de activación y desactivación, ya sea mediante el código fuente o una interfaz de configuración. | Leonel / Josue |
| | | **COMUNICACIONES:** | |
| | E | El sistema debe transmitir mediante WiFi los datos de humedad y el estado del riego (activo / detenido) hacia una plataforma IoT (por ejemplo, Blynk o ThingSpeak) al menos una vez por minuto. La información transmitida debe poder visualizarse en tiempo real desde un dispositivo móvil o navegador web, con un retraso máximo de 10 segundos respecto a la lectura del sensor. | Leonel / Giordano / Josue |
| | | **USO:** | |
| | E | El usuario debe poder conocer el estado del sistema (regando / detenido) mediante un indicador visual (LED) en el prototipo y/o mediante la plataforma IoT, sin necesidad de conocimientos técnicos previos. El sistema debe operar de forma automática durante el uso normal, requiriendo intervención del usuario únicamente para la configuración inicial o el mantenimiento periódico. | Josue / Kenneth |
| | | **MANTENIMIENTO:** | |
| | E | Los componentes principales (sensor, controlador, actuador) deben poder revisarse o reemplazarse en menos de 10 minutos, sin necesidad de desmontar por completo la estructura, mediante conexiones desmontables (tornillos o conectores rápidos). El sensor de humedad debe poder retirarse del suelo para su limpieza sin dañar el cableado ni requerir herramientas especializadas. | Leonardo / Josue |
| | | **FABRICACIÓN:** | |
| | E | El prototipo debe construirse utilizando materiales y componentes disponibles comercialmente, dentro del presupuesto asignado por el curso al equipo, y con procesos de fabricación viables en los plazos del semestre. El equipo debe elaborar una lista de materiales (BOM) que indique cantidad, función y costo aproximado de cada componente utilizado en el prototipo. | Kenneth / Leonardo / Giordano |
| | | **MONTAJE:** | |
| | E | El montaje del sistema debe realizarse siguiendo el diseño mecánico y electrónico aprobado por el equipo, verificándose mediante inspección visual antes de iniciar las pruebas funcionales. El sensor de humedad debe instalarse a una profundidad de entre 5 y 10 cm en el sustrato, y los demás componentes en posiciones que garanticen mediciones representativas del área regada. | Leonardo / Leonel / Kenneth |
| | | **CONTROL DE CALIDAD:** | |
| | E | Antes de la presentación del prototipo, el equipo debe verificar el funcionamiento de sensores, controlador, actuador, conexiones y comunicación IoT mediante una lista de verificación (checklist) documentada. Los resultados de cada prueba (fecha, resultado obtenido, responsable) deben registrarse como evidencia del funcionamiento del prototipo, previa a la entrega final. | Kenneth / Leonel / Josue |
| | | **DOCUMENTACIÓN:** | |
| | E | El proyecto debe contar con documentación que incluya el diagrama de conexión, el código fuente comentado y un manual breve de uso del sistema de riego. La documentación debe actualizarse cada vez que se modifique el diseño mecánico, electrónico o el software, indicando la fecha del cambio y el responsable de la actualización. | Josue / Giordano / Leonel |
| | | **INTEGRACIÓN:** | |
| | E | Los módulos mecánico, electrónico y de software deben integrarse y probarse en conjunto antes de la entrega final, validando el funcionamiento del prototipo como un sistema único de riego automatizado. | Kenneth / Leonardo / Leonel |

**Leyenda:**
